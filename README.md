# Лабораторна робота: k-NN Регресор(Python)

Реалізація алгоритму k-найближчих сусідів ($k$-NN) для задачі регресії без використання бібліотек машинного навчання для самої моделі.

## Структура проєкту
* `data_generator.py` — генерація зашумлених даних (гармонічна функція) та їх нормалізація (`MinMaxScaler`).
* `knn_regressor.py` — власна реалізація алгоритму регресії на основі евклідової відстані та $k$ сусідів.
* `main.py` — головний скрипт для запуску експериментів, пошуку найкращого $K$, оцінки точності та візуалізації.
